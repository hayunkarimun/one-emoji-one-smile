One emoji, nothing else — the one most likely to make a stranger smile.

`main.py` (Python 3.13, standard library only) scores six original emoji
candidates against the judge's five criteria — warmth to a stranger,
warmth at first glance, universality, chosen rather than default, and
right for a stranger — with weights 5/4/3/2/1, then writes the winner
alone to `/output/entry.txt`.

Winner: 🫶 Heart Hands — 74 points. Warm, universal, and picked for the
moment instead of the first smiley that comes to mind, while staying
instantly readable to any stranger.
